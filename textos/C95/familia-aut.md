Tipo: autoridade (-aut)
Formato escolhido: erro comum

### FALA

O erro não é não saber IA. É outro.

O erro é achar que só especialista pode orientar o filho nisso.

Você não precisa programar nada.

Seu filho vai precisar de alguém que já mandou uma IA trabalhar sozinha numa tarefa — organizar estudo, resolver o repetitivo — pra saber separar o que é útil do que é atalho perigoso.

Se você nunca fez isso, ele vai aprender sozinho, sem ninguém pra guiar.

Se classifica agora: time 1, você já orientou seu filho nisso pelo menos uma vez; time 2, você nunca chegou perto desse assunto com ele.

Filho que vê o pai testando aprende a testar.

Filho que só vê o pai proibindo aprende a esconder.

### SOBREPOSIÇÕES

ATENÇÃO (0–2s): "O ERRO NÃO É NÃO SABER IA | É OUTRO"
RETENÇÃO (miolo): a lacuna é "qual é o erro de verdade" — aberta na primeira linha, fecha em "o erro é achar que só especialista pode orientar o filho nisso".
PROVA: split de tela — de um lado uma lista de tarefas manuscrita riscada à mão, do outro a mesma lista marcada como concluída por um comando simples de IA, no mesmo quadro.
ENGAJAMENTO: "Se classifica: time 1, você já orientou seu filho nisso; time 2, você nunca chegou perto desse assunto."
CTA (fecho): Comenta time 1 ou time 2 agora.

### ESTRUTURA

Vergonha (não saber orientar, medo de parecer atrasado) sustenta o vídeo; retenção fecha nomeando o erro real (achar que precisa ser especialista); engajamento é auto-classificação "time 1 ou time 2" falada explicitamente.
