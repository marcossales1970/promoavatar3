Tipo: autoridade
Formato escolhido: conceito explicado

### FALA
Você usa só uma inteligência artificial pra tudo? Isso te custa tempo sem você perceber.
Cada modelo de IA é bom numa coisa diferente. Um escreve melhor, outro faz imagem melhor, outro é mais rápido, outro é mais barato. Usar sempre o mesmo é como cozinhar tudo na mesma panela, do arroz à sobremesa.
Existe um jeito de resolver isso: um sistema que aprende sozinho o que cada ferramenta de IA faz bem, e escolhe a certa pra cada tarefa. Você pede uma coisa, e ele reescreve seu pedido do jeito que cada ferramenta entende melhor. O mesmo pedido, adaptado pra cada uma.
Salva esse vídeo. Da próxima vez que for pedir algo pra uma IA, pergunte: essa é a ferramenta certa pra isso, ou é só a que eu já conheço?

### SOBREPOSIÇÕES
ATENÇÃO (0-2s): você usa só uma IA pra tudo?
RETENÇÃO (miolo): cada modelo é bom numa coisa diferente
PROVA: tela comparando três resultados diferentes pro mesmo pedido, cada um de uma ferramenta
ENGAJAMENTO: pergunte se é a ferramenta certa ou só a que você já conhece
CTA (fecho): salva esse vídeo
