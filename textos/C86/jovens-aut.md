Tipo: autoridade
Formato escolhido: ensino de método concreto (passo a passo demonstrado)
Ganchos descartados: 1) "Vou te ensinar a montar um projeto com IA" — declara autoridade em vez de demonstrar, proibido pela regra do tipo. 2) "Existem quatro etapas pra sair da ideia" — número solto sem lacuna forte. 3) "A maioria começa pelo lado errado de um projeto" — boa mas repete o formato de crítica do -alc. 4) "Primeira versão funcional não é sistema pronto" — já se basta, não abre pergunta.

### FALA
Ideia boa sozinha não vira renda. Vira projeto quando alguém termina ela.

Repara na ordem que funciona de verdade. Primeiro, você define o problema que quer resolver — não a ferramenta que quer usar.

Depois, você desenha o caminho mais curto até uma versão que funciona, mesmo que pequena.

Só então entra a IA: pra escrever código, gerar conteúdo, montar automação — o que o projeto pedir.

E no fim, você testa com uma pessoa de verdade usando aquilo.

Um jovem que segue essa ordem não constrói um sistema completo em cinco dias. Constrói a primeira versão funcional — a prova de que ele sabe transformar ideia em coisa que roda.

Guarda esse princípio: ferramenta entra depois do problema, nunca antes.

Salva esse vídeo pra seguir a ordem quando for começar o seu.
